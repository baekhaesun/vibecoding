STEP 04 · 4~5차시

친구의 생각을 읽고 연결하다

공동 데이터 읽기 → 비교·분석 → AI와 다시 읽기

교과 융합 포인트 🧩

📖 국어 · 🌎 영어 · 💻 정보 · 🤖 AI인문학

  • 📖 국어 | 친구들의 글을 읽고 공통점·차이점·근거를 찾아 요약해요.
  • 🌎 영어 | 핵심 단어나 짧은 표현을 영어로 바꾸어 의미 차이를 살펴볼 수 있어요.
  • 💻 정보 | 여러 사람의 데이터를 공동 웹에서 읽기 쉬운 형태로 연결해요.
  • 🤖 AI인문학 | AI의 요약이 모든 사람의 목소리를 공정하게 담는지 원자료와 비교해요.

오늘의 AI인문학 질문 🤔

많은 사람의 생각을 AI가 요약하면 사라지거나 작아지는 목소리는 없을까?

정답을 찾기보다 활동 전·후에 내 생각이 어떻게 달라졌는지 기록해 봐요.

4차시 · 친구의 생각을 읽다 👀

  • 친구들이 입력한 데이터를 직접 읽고 반복되는 생각과 서로 다른 생각을 찾아요.
  • ‘많다/적다’만 보지 않고 인상적인 한 사람의 의견도 살펴봐요.
  • 공동 데이터를 카드·목록 등 읽기 쉬운 형태의 웹으로 연결해요.

5차시 · AI와 함께 다시 읽다 🤖

  • 먼저 내가 공통점·차이점을 찾고 근거를 표시해요.
  • 같은 자료를 AI에게 분석하게 한 뒤 내 분석과 비교해요.
  • AI가 놓친 의견이나 자료에 없는 해석이 있는지 원문으로 다시 확인해요.

AI에게 이렇게 말해 볼까요? 💬

다음은 우리 반이 모은 데이터야: [데이터]. 공통점 3개와 서로 다른 의견 2개를 찾아줘. 각 판단의 근거가 되는 실제 내용을 함께 보여줘. 소수 의견도 따로 확인하고, 자료에 없는 내용은 추측하지 마.

비교 기록 🔍

내가 발견한 것 → AI가 발견한 것 → AI가 놓친 것 → 원자료를 다시 보고 판단한 것 순서로 기록해요.
