웹페이지 움직이기

버튼을 누르면 반응하는 페이지

오늘의 미션 ✨

  • 1차시 페이지에 버튼을 추가해요.
  • 클릭 전후에 무엇이 달라지는지 확인해요.
  • 움직이지 않으면 증상을 AI에게 정확히 설명해요.

AI에게 이렇게 말해 볼까요? 💬

관심사 버튼을 누르면 설명 문장이 나타나고 다시 누르면 숨겨지게 해줘. 다른 내용은 유지해줘.

기억해요 🌱

버튼을 눌러도 아무 변화가 없어. 원인을 확인하고 고쳐줘.

말한다 → 실행한다 → 확인한다 → 한 가지씩 고친다!
