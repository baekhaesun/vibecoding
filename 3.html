STEP 03 · 3차시

생각을 데이터로 남기다

주제와 입력 항목 설계 → Google Sheets 저장

교과 융합 포인트 🧩

📖 국어 · 💻 정보 · 🤖 AI인문학

  • 📖 국어 | 무엇을 묻고 어떤 답을 받을지 질문과 입력 항목을 언어로 설계해요.
  • 💻 정보 | HTML 입력 화면과 공용 Apps Script를 연결해 Google Sheets에 저장해요.
  • 🤖 AI인문학 | 사람의 생각이 데이터로 바뀔 때 무엇이 남고 무엇이 사라지는지 생각해요.

오늘의 AI인문학 질문 🤔

우리의 생각이 데이터가 되면 무엇을 알 수 있고, 무엇은 알기 어려울까?

정답을 찾기보다 활동 전·후에 내 생각이 어떻게 달라졌는지 기록해 봐요.

오늘의 활동 ✨

  • 친구들에게서 모으고 싶은 생각의 주제를 정해요.
  • 주제를 잘 드러낼 수 있는 질문과 입력 항목 2~3개를 만들어요.
  • 교사가 제공한 공용 Apps Script 저장 기능은 유지하고 웹 화면을 내 주제에 맞게 바꿔요.
  • 테스트 데이터를 입력하고 Google Sheets에 정확히 저장되는지 확인해요.

AI에게 이렇게 말해 볼까요? 💬

이 HTML은 공용 Google Sheets에 데이터를 저장하는 웹앱이야. 주제를 [주제]로 바꾸고 입력 항목을 [항목1], [항목2], [항목3]으로 구성해줘. SCRIPT_URL과 데이터 전송 기능은 변경하지 마. 개인정보를 받는 항목은 만들지 마.

생각하며 확인하기 🔍

  • 숫자나 짧은 답만으로 친구의 생각을 충분히 알 수 있을까요?
  • 질문을 어떻게 만드느냐에 따라 모이는 데이터가 달라지지 않을까요?
  • 이름·전화번호·집 주소 등 불필요한 개인정보는 수집하지 않아요.

결과물 🎁

나만의 데이터 수집 웹앱 + 질문·입력 항목을 그렇게 정한 이유
